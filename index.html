「关于作品数据的问题，都可以问我。」

通用入口文案 — 用户看完数据，仍不知道问什么

「你的完播率低于同层作者，建议从前 3 秒开头钩子入手；互动率偏弱，可在结尾追加提问引导。」

基于用户最弱指标主动生成 — 建议可直接执行（示意）

该方案提问 UV 率 11%

  • 数据洞察：用 SQL 对比“点击过作品表现面板底部 AI 创作助手入口”的作者与未点击作者，发现 AI 使用率分别为 25% 与 11%；进一步拆解“查看数据→点击入口→提问→发布作品”漏斗，定位主要问题不是功能没有价值，而是用户看完数据后缺少明确的下一步动作。
  • 需求与分层：通过创作者访谈和行为观察，归纳出“不知道问什么、建议与自身数据无关、建议难执行”三类需求；按新用户、已查看数据但未提问、已提问未发布等行为分层，分别设计入口文案、触达时机和个性化提问内容，并为不同人群设定提问、采纳和发布等阶段性指标。
  • 内容运营与落地：围绕 CTR、完播率、互动率等高频指标整理问题—原因—动作内容模板，输出用户侧引导话术、运营方案和交互原型；推动产品、算法和模型团队接入作品数据，使 AI 根据用户最弱指标主动生成可执行的创作建议，并跟进上线后的内容质量与用户反馈。
  • 实验与复盘：对入口位置、主动诊断 vs 固定模板、个性化 vs 通用提问分别开展 A/B 实验，比较提问率、建议采纳率和后续发布行为；根据实验结果调整入口文案、触达时机和推荐内容，最优方案推全后用 1.2 亿 UV、5% 对照组做 3 个月反转验证，提问 UV 率由 11% 提升至 39%，主动诊断与个性化提问贡献约 20PP。

示意 · 猎头澄清经验 Skill 化，由 Agent 主动追问

找个懂增长的人
收到，先确认几个关键约束：
① 偏投放、内容还是商业化增长？
② 期望年限区间？
③ 行业背景有要求吗？
内容增长，3 年左右，最好有短视频行业经验
约束已补全内容增长3 年+短视频→ 生成精准搜索
  • 需求挖掘：访谈 30+ 招聘方并整理真实搜索 Case，按岗位、能力、行业、年限等字段编码，发现“找个懂增长的人”这类需求普遍缺少关键约束；结合搜索失败样本判断，核心问题是输入信息不足，而非单纯的推荐算法问题。
  • 方案与执行：绘制“需求输入—意图澄清—人才搜索—结果反馈—触达”的流程原型，设计澄清问题、结果解释和反馈文案；搭建招聘场景 Agent Demo，将猎头 Know-How 拆为意图澄清、人才搜索、触达、看板管理四组 Skill，并用 Few-shot 和 RAG 知识库注入专业信息。
  • 评测与迭代：制作意图澄清 200+ case、搜索 100+ case 的标准评测集，覆盖模糊、矛盾、跨领域输入；用“澄清完成率—有效搜索率—结果采纳率—后续触达”漏斗定位问题，Prompt 改动统一跑回归测试。
  • 用户验证：4 周内让 22 名真实 HR 试用，收集 60+ 反馈并完成 4 轮迭代；按反馈频次和业务影响排序问题，重点优化澄清轮次、结果解释和操作路径，并沉淀为可复用的试用运营流程，从 Demo 推进至可运营产品。

项目成果推荐准确率 60% → 85%+，意图澄清 Skill 独立贡献约 15PP；需求首次满足率 35%→68%。
